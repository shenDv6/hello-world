# 知识讲解动效视频（Explainer Motion Video）

代码不是瓶颈，**导演和设计才是**。AI 默认产出的“廉价感”几乎都来自同一批问题：
线性缓动、只会淡入、所有元素同时出场、居中漂浮的大字、纯黑背景、占位假数据、
每一幕独立设计互不衔接、做完不看就交付。本 skill 就是专门堵这些洞的。

先读 `references/reference-breakdown.md`：一条 1000+ 转发的标杆视频的逐幕拆解，
它是本 skill 所有规则的“正确答案”。

## 流程（按顺序，每步有产物，不许跳）

| 步骤 | 产物 | 要点 |
| --- | --- | --- |
| 1. 立意 | 一句话 `这条视频让【谁】在【几秒】里明白/感受到【什么】` | 找一个钩子：反常识的数字、放慢/放大、拟人化视角 |
| 2. 分镜 | `STORYBOARD.md` 表格 | 每一幕：时长 / 一句屏幕文案 / **视觉隐喻** / 主元素动词 / 真实内容 / 转场 |
| 3. 设计系统 | `src/theme.ts` | 先定死：底色、前景色、**唯一**强调色、字体三件套、网格边距、HUD 规范 |
| 4. 搭建 | Remotion 工程 | 先写全局层（背景/HUD/颗粒/暗角），再逐幕写 |
| 5. 声音 | `public/audio/*.wav` | 没素材就用 Node 合成（pad + tick + whoosh），绝不交无声片 |
| 6. 渲染 + 自检 | `out/video.mp4` + 接触表 | **必须**抽帧拼图自己看，按清单修，修完重渲再看 |

起步：复制 `assets/template/`（实测可渲染：HUD、星尘、颗粒、暗角、中文字体、错峰入场、配乐），
音频用 `scripts/gen-audio.mjs` 合成。命令见 `references/remotion-implementation.md`。

详细规则：
- 叙事与分镜 → `references/story-and-storyboard.md`
- 视觉设计（版式/色彩/字体/HUD/数据可视化）→ `references/visual-design.md`
- 动效（缓动/节奏/转场/连续性）→ `references/motion.md`
- Remotion 技术实现、中文字体、音频合成、渲染与抽帧 → `references/remotion-implementation.md`

## 十条硬规则

1. **每一幕先有隐喻，再有像素。** “向量”不是一排数字，是“每个字展开成一条彩色条码”；
   “语义”是“意思相近的词住得近的星空”。写不出隐喻的幕 = 还没设计好。
2. **真实内容，不要占位符。** 词表、概率、编号、坐标都要编得像真的（并在片尾注明“数值为示意”）。
   `Lorem`、`Item 1`、`xxx` 一律禁止。
3. **一个强调色**，其余用它调出的中性色。全片只在“情绪转折”那一刻换色温（如冷青 → 暖琥珀）。
4. **有一套贯穿全片的“界面外壳”（HUD）**：章节号 + 中文标题 + 英文小字、分段进度条、
   右上角计数器/时间码。它让几十幕看起来是**一个**作品，而不是几十张 PPT。
5. **版式靠边对齐，有网格。** 标题左对齐放在上 1/5；安全区左右 ≥ 6% 边距；
   9:16 关键内容在中间 75% 高度内。居中漂浮只留给结尾的仪式感时刻。
6. **永不线性缓动；出场至少动 2 个属性**（opacity + y/scale/blur）；**错峰**（每个 3–6 帧）；
   **退场比入场快**（约 0.75 倍）。
7. **节奏要有停顿**：动作 → 0.3–0.75 秒静止 → 结果。一直在动 = 业余；快慢对比 = 高级。
8. **前景必须“在表演”**：任意一帧暂停，画面里都应有东西正在揭示/推进/计数。
   背景粒子可以缓慢漂浮，但不能靠前景元素原地呼吸来“填时间”——那是剧情不够。
9. **幕与幕之间有连续性**：上一幕怎么离开，下一幕就沿同一方向/同一缩放趋势进来；
   能用“同一个元素变形过去”（比如那句话被切成词块）就别用淡入淡出。
10. **渲染后必须抽帧看图**（`references/remotion-implementation.md` § 自检），不看不交付。

## 交付前清单

- [ ] 立意一句话写得出来；每幕都能追溯到它，追溯不到的幕删掉
- [ ] 没有任何线性 `interpolate`；所有 `interpolate` 都 clamp
- [ ] 所有随机都用 `random(seed)`，渲染两次结果一致
- [ ] 一个强调色；同一帧里发光的主元素 ≤ 1 个
- [ ] 中文用 Noto Sans SC / Noto Serif SC 等真实加载的字体，数字用等宽字体 + `tabular-nums`
- [ ] 标题字号 ≥ 56px（1080 宽），正文 ≥ 32px，标注 ≥ 20px；装饰透明度 ≥ 10%
- [ ] 背景不是纯 `#000`：有径向光、颗粒、暗角、粒子至少两样
- [ ] 至少 3 处明显的“静止 → 爆发”节奏
- [ ] 有配乐，关键落点有音效，音效比画面**早 2–3 帧**
- [ ] 抽帧接触表已人工检查：无溢出、无穿帮（元素提前出现/残留）、无文字贴边
- [ ] 片尾有签名/出处，数值是示意的要写明
