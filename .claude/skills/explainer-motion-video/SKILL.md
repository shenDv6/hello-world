# 知识讲解 / 宣传动效视频

代码不是瓶颈，**导演和设计才是**。AI 默认做出来的“廉价感”几乎都来自同一批问题：
线性缓动、只会淡入、所有元素同时出场、居中漂浮的大字、纯黑背景、占位假数据、
每一幕单独设计互不衔接、做完不看就交付。本 skill 专门堵这些洞。

先读 `references/reference-breakdown.md`：一条 1000+ 转发的标杆视频的逐幕拆解，是本 skill 规则的“正确答案”。

## 选路线

| | Remotion 路线 | WebGL 路线 |
| --- | --- | --- |
| 模板 | `assets/template/` | `assets/webgl-template/`（完整 90 秒成片源码） |
| 擅长 | 排版、HUD、UI、数据图表；冷静的科技感和纪录片感 | 上万粒子、泛光、粒子拼成文字、彩纸爆炸；震撼或明亮活泼的风格 |
| 速度（无 GPU 沙箱） | 90 秒约 5 分钟 | 90 秒约 30 分钟（0.66 秒/帧），可以只重渲改过的段落 |
| 文档 | `references/remotion-implementation.md` | `references/webgl-pipeline.md` |

用户点名要“它那种技术栈”，或者要“光效、粒子、震撼、活泼有活力”时，用 WebGL 路线；以文字、UI 讲解为主时，用 Remotion 路线。

## 流程（按顺序，每一步都有产物，不要跳）

| 步骤 | 产物 | 要点 |
| --- | --- | --- |
| 1. 立意和资料 | 一句话：`这条视频让【谁】在【几秒】里明白/感受到【什么】`；把事实和出处列出来 | 涉及真实机构时，数据只用能查到的公开报道，片尾写明来源 |
| 2. 文案和分镜 | `vo-script.json` + `STORYBOARD.md` | 每一幕写清：旁白、**视觉隐喻**、主元素动词、真实内容、转场。先给用户看文案 |
| 3. 旁白 | 每句一个 WAV + `vo.json` 时间轴 | `scripts/tts.py`，先发 2–3 个音色的试听样本；调停顿凑到目标时长。见 `references/voiceover.md` |
| 4. 设计系统 | 主题色、字体、网格 | 底色、前景色、强调色都先定死；每一幕颜色怎么变也提前规划好 |
| 5. 搭建 | 工程代码 | 从模板复制；所有落点都用 `word(line, "词")` 对齐到旁白 |
| 6. 声音 | 配乐 + 音效 + 旁白混音 | 没有素材就用代码合成；音效和画面落点用同一份数据；旁白出现时音乐自动压低 |
| 7. 渲染和自检 | 成片 + 接触表 + 频谱图 + 同步报告 | **必须**抽帧拼图自己看；测响度（-14 LUFS）和音画同步；修完再渲 |
| 8. 交付 | 分享版（30 MB 以内）+ 高清母版；源码提交推送 | 如实说明：哪些验证过，哪些要用户自己听、自己看 |

## 十条硬规则

1. **每一幕先有隐喻，再有像素。** “向量”不是一排数字，是“每个字展开成一条彩色条码”。
2. **真实内容，不要占位符。** 数据要真实可查（或者明确标注“示意”），不要写 `Lorem`、`xxx`。
3. **一套配色贯穿全片**；色温或主色调要变，就在情绪转折点变，而且要有理由。
4. **贯穿全片的“外壳”**：HUD、章节标签、进度条、字幕样式全片统一，让几十幕看起来是**一个**作品。
5. **版式靠边对齐、有网格**；竖屏关键内容放在中间 75% 高度内，底部 20% 留给平台 UI 和字幕。
6. **永远不用线性缓动；出场至少动 2 个属性；错峰出场；退场比入场快。**
7. **节奏有停顿**：动作 → 0.3–0.75 秒静止 → 结果。大落点配闪白、震屏、冲击音。
8. **任意一帧暂停都有东西在推进**；不许出现几秒的空白卡片或空镜。
9. **幕与幕之间要连贯**：同一个对象变形过去（线 → 大脑、粒子 → 文字 → 彩纸），不要一直淡入淡出。
10. **渲染后必须抽帧看图 + 测同步和响度**，不看不交付。

## 交付前清单

- [ ] 立意一句话写得出来；每一幕都能追溯到它
- [ ] 数据都有出处，片尾写明；集团层面的数据没有说成地方分公司的
- [ ] 没有线性缓动；随机数全是种子化的；可以任意跳帧重渲
- [ ] 中文字体真正加载了（不是回退字体）；全片的文字都预加载过
- [ ] 标题 ≥ 56px，正文 ≥ 32px，字幕不会孤零零掉一个字到第二行
- [ ] 接触表检查过：没有溢出、重叠、空镜，没有元素提前出现或残留
- [ ] 响度约 -14 LUFS，真峰值 ≤ -1.5 dBFS；关键落点音画偏差 ≤ 1 帧
- [ ] 帧率、时长符合要求（拼接后要确认）；分享版在 30 MB 以内
- [ ] 源码已提交推送，渲染产物没有进 git
