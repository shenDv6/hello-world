# 动效

你知道这些规则，但你总在违反它们。逐条对照。

## 1. 缓动就是情绪

- **永远不用线性缓动**（只有匀速滚动、计时器这类“机械匀速”是例外，而且要有意为之）。
- 入场用 `out`（先快后慢），退场用 `in`（先慢后快），位置之间的移动用 `inOut`。别搞反：入场用 in 会显得拖沓。
- 同一种元素用同一种缓动 + 时长；不同角色的元素用不同的缓动。一幕里同一条曲线最多用两次。
- 不用 `bounce` / `elastic`；轻微过冲（`back.out(1.4)` 或弹簧 `damping ~ 12–18`）可以用。

Remotion 常用预设：
```ts
import { Easing } from "remotion";
export const ease = {
  out: Easing.bezier(0.16, 1, 0.3, 1),     // expo-out，干脆利落
  inOut: Easing.bezier(0.65, 0, 0.35, 1),
  in: Easing.bezier(0.7, 0, 0.84, 0),
  soft: Easing.bezier(0.33, 1, 0.68, 1),   // 柔和
};
export const springs = {
  smooth: { damping: 200 },                // 无回弹推入
  snappy: { damping: 20, stiffness: 200 },
  heavy: { damping: 30, stiffness: 80, mass: 1.5 }, // 大元素慢慢落定
};
```

## 2. 时长就是重量

| 速度 | 时长 | 感觉 | 用在 |
| --- | --- | --- | --- |
| 快 | 0.15–0.3s | 干脆、紧迫 | 小标签、数据点、退场 |
| 中 | 0.3–0.5s | 专业 | 大多数内容入场 |
| 慢 | 0.5–0.8s | 郑重 | 标题、主视觉 |
| 很慢 | 0.8–2s | 电影感、抒情 | 结尾、升华、镜头推移 |

单个元素入场 ≤ 0.8s；更长的铺陈用多个元素错峰，不要让一个元素慢慢挪。

## 3. 入场、错峰、退场

- 入场至少动 2 个属性：`opacity` + `translateY`/`scale`/`blur`。只做淡入 = 廉价。
- 方向要有变化：不要所有元素都从 `y: 30` 淡入。可以从左、从缩放、从模糊、从字距收拢进来。
- 错峰：字 2–3 帧，列表项 4–5 帧，大块 6 帧；整组错峰总长 ≤ 0.5s。
- 出场顺序 = 重要程度顺序（最先动的被认为最重要），不一定是 DOM 顺序。
- 退场时长 ≈ 入场的 75%，用 `in` 缓动；先出现的先离开。
- 第一个动画不要从第 0 帧开始，偏移 3–8 帧。

## 4. 每一幕的三段式：铺陈 / 表演 / 收束

- **铺陈（0–30%）**：元素错峰进场。
- **表演（30–75%）**：前景继续“讲故事”——分阶段揭示、计数推进、高亮移动、镜头推近。
  **暂停测试**：任意一帧暂停，都要有东西正在推进。
  前景元素原地呼吸/漂浮来“填时间”是剧情不够，要加内容，而不是加晃动。背景粒子漂浮可以。
- **收束（75–100%）**：退场，或者直接变形成下一幕。

## 5. 静止是高级感的来源

- **高潮前留白**：大动作和结果之间停 0.3–0.75 秒（“掷骰子 → 定格 → 停一拍 → 凉”）。
- 快动作 → 完全静止 → 下一个动作。一直匀速在动的画面显得业余。
- 全片至少 3 处明显的“静止 → 爆发”。

## 6. 幕与幕的连续性（最能拉开差距的一点）

每一幕单独设计 = 一叠 PPT。要让全片像**一个连续的镜头**：

- **同一个对象贯穿**（首选）：上一幕的主元素变形成下一幕的主元素，比如那句话 → 词块 → 编号 → 条码 → 星点。同一个 React 组件跨幕持续存在，靠插值改它的布局。
- **方向律**：上一幕往哪个方向离开，下一幕就从同一方向继续进来（左出就从右进，保持向左的“水流”）；
  Z 轴也一样——上一幕是推近（放大）的，下一幕也要继续推近，不能突然变成从小放大。
- **速度匹配**：上一幕用 `in` 加速离开，下一幕用 `out` 从高速进来，两边在切点速度都最快，看起来就是一个运动。
- **切在运动中**：不要等上一幕完全停下再切，也不要让下一幕从静止开始。
- **少用淡入淡出**：交叉淡化没有“载体”，眼睛失去跟随对象。全片只用 2–3 种转场，反复用。
- 方向改变要有原因（点击、碰撞、章节边界）。

转场速查（Remotion 手写实现，8–14 帧）：
- **推移**：A `x: 0 → -300, blur 0 → 16px`（in）｜B `x: 300 → 0, blur 16 → 0`（out）
- **穿越推近**：A `scale 1 → 1.25 + blur`（in）｜B `scale 0.85 → 1 + blur`（out）
- **遮罩擦除**：强调色块扫过画面，切点藏在色块后面
- **硬切**：卡在音乐重拍上，适合节奏快的连续短镜头

## 7. 因果链

动作要一个引发下一个：点击 → 压缩 → 弹出 → 飞行 → 撞击 → 回弹 → 揭示。
被引发的效果在**同一帧**开始，不要“稍晚一点”。大元素反应慢，小元素反应快。

## 8. 文字动画

- 标题：整句快速进场（0.4s，`opacity + y 24px + blur 8px → 0`），每幕替换。
- 打字机：输入框、终端里用，每 2 帧一个字，带闪烁光标（光标闪烁用 `frame % 30 < 15`，不要用 CSS 动画）。
- 逐字出现：抒情段落用，每字 4–6 帧，`opacity + blur`，慢 = 郑重。
- 数字滚动：用 spring 或 `ease.out` 驱动，等宽字体 + `tabular-nums`，定格时强调色闪一下。
- 高亮一个词：词落定 5 帧后，强调色 / 下划线从左画出 / 背景胶囊放大。
