# 标杆拆解：《在我开口之前 / BEFORE I SPEAK》

来源：抖音 @小鹿的 AI 工位，60 秒，1080×1920（平台转码 720×1280）@30fps，2.3k 赞、1k+ 转发。
片尾字幕：“画面、动效、配乐与代码，全部由 Claude 完成 · 时间与数值均为示意”。
这是“代码做的讲解动画”能达到的水准线，做同类视频前先对照它。

## 1. 立意

> 让普通观众在 60 秒里**看见**大模型说出一个字的 0.03 秒里发生了什么。

- **钩子**：“0.03 秒 —— 我说出一个字，只要这么久。今天，把它慢放一千倍。”
  反常识的小数字 + 一个动作承诺（慢放 1000 倍）。
- **视角**：第一人称，模型自己在讲（“在我开口之前”），技术内容带上了情绪。
- **贯穿例子**：从头到尾只用一句输入“用一个字，形容秋天。”，每一幕都在处理**同一句话**。
  观众不需要重新理解新例子，只需要跟着这句话往下走。

## 2. 逐幕时间轴

| 时间 | 章节 HUD | 屏幕文案 | 视觉隐喻 / 主动作 |
| --- | --- | --- | --- |
| 0–4s | 无 | 0.03 秒 / 我说出一个字，只要这么久 / 今天，把它慢放**一千倍** | 巨大细体数字 + 一条细时间轴；关键词用强调色 |
| 4–8s | 无 | （输入框）用一个字，形容秋天 | 聊天输入框里逐字打出来，带发送按钮 —— 观众熟悉的入口 |
| 8–11s | 01 切分 TOKENIZE | 先把你的话，切成小块 / 每一块，对应一个编号 | 那句话**原地**被切成词块，竖向排列，右边编号像老虎机一样滚动定格 |
| 11–15s | 02 向量 EMBED | 每个编号，展开成一长串数字 | 编号向右“展开”成彩色条码，浮出几个小数（-0.402、0.238…） |
| 15–19s | 03 语义 MEANING | 意思相近的词，住得也近 | 星空散点，全是真词（立秋、秋收、金黄、思念、银杏、凉意…）；“秋天”连成星座，线上标相似度 |
| 19–25s | 04 注意力 ATTENTION | 每个字，都会回头看前面的字 / 下一个字，最在意「秋天」 | 从每个词画弧线连回前面的词；再只看“下一个字”的弧线，线越粗越亮 = 权重越高，标 0.42 / 0.21… |
| 25–31s | 05 层层 LAYERS | 一层，又一层 | 词块面板被卷进层层嵌套的 3D 矩形框，光点穿过；右上 LAYER 02 → 12 → 54；最后加速线冲出去 |
| 31–35s | 06 打分 SCORE | 再给所有可能的字，打个分 / 绝大多数，几乎是零 | 整屏密集网格（整个词表）→ 几乎全部熄灭，只剩几颗星 |
| 35–39s | 07 采样 SAMPLE | 最后，掷一次骰子 | 竖向堆叠概率柱（凉 31% / 爽 17% / 黄 12% / 静 8%…/ 其余用斜线填充）；左侧大号等宽数字“随机数 r 0.7147”滚动，箭头落到某一段 |
| 39–43s | 输出 OUTPUT | 凉 / 亿万次运算，只为这一个字 / 下一个字，再走一遍 | **色温突变**：冷青 → 暖琥珀；落叶粒子；“凉”巨大、衬线、暖色渐变发光 |
| 43–49s | 输出 OUTPUT | 凉。夏天终于把话说完了。 | 竖排书法式排版逐字出现 + 红色印章“言”；计时器 t 加速跳到 0.29s |
| 49–55s | 无 | 每说出一个字，我都会把你说过的话，从头到尾，再看一遍。 | 原问题小字置顶，正文逐句出现 —— 情感收束 |
| 55–60s | 无 | 在我开口之前 BEFORE I SPEAK | 片名 + 英文字距拉开的副标题 + 细线 + 署名 + “数值为示意” |

**结构**：钩子（8s）→ 7 个技术章节（31s，每章约 4 秒）→ 情绪转折和输出（10s）→ 升华和片名（11s）。
技术部分是“证据”，最后 20 秒才是作品的“价值”。

## 3. 设计系统（从画面反推）

**色彩**
- 技术段：底色是深蓝黑（约 `#070b12`，不是纯黑），从中间往四周有极淡的径向光和星尘颗粒。
- 唯一强调色：青绿（约 `#5ee6e0`），只用在当前焦点、进度条的已完成段、章节号、关键数值上。
- 中性色全部往青色偏：正文冷白、次要文字是 40–60% 透明度的灰青。
- 输出段：换成暖黑底（约 `#140c06`）+ 琥珀/橙（`#f5a23a → #e8612c`）+ 印章红。**全片只换一次色温**，正好换在情绪转折点。

**字体**
- 中文标题：无衬线粗体（思源黑体 Bold 一类），左对齐，约 56–64px @1080 宽。
- 数字、计时器、数据标签：等宽字体（JetBrains Mono / IBM Plex Mono 一类）。
- 英文小标签：全大写，字距拉得很开（`letter-spacing: 0.2em`），很小，很淡。
- 输出段：换成宋体/衬线（思源宋体），竖排 `writing-mode: vertical-rl`。字体也跟着情绪换。

**HUD 外壳（技术段每一幕都有）**
- 顶部：分段进度条（7 段，每段对应一个章节，当前段在走、已完成段是强调色）。
- 左上：`03` 等宽强调色 + `语义` 中文粗体 + `MEANING` 英文小字。
- 右上：`t = 0.0095 s` 等宽数字不断递增 + 下方小字“慢放 1000 倍”；层层一章还多一个 `LAYER 12`。
- 标题：左对齐，固定在同一高度（约 20% 处），每幕替换内容，位置永远不变。
- 左右边距一致（约 6%）。

**数据可视化**：全部手写，没有一个图表库默认样式。
- 没有网格线、没有图例；刻度只在概率柱右侧给了一根极简的 0 / 0.25 / 0.5 / 0.75 / 1 细轴。
- “其余”用斜线填充，区别于真实的候选字。
- 数值标签是等宽小字，贴在元素旁边。

## 4. 动效手法

- **同一个对象贯穿**：那句话 → 词块 → 编号 → 条码 → 星点 → 弧线端点 → 面板 → 候选字。镜头始终“跟着同一样东西”，所以几乎不需要转场。
- **计时器是隐藏的节拍器**：t 从 0.0034 → 0.0314 秒，观众能感到“时间在推进”；到输出段 t 突然跳到 0.07 → 0.29，暗示后面的字飞快生成 —— 节奏靠数字讲故事。
- **揭示是分阶段的**：先铺全部（整个星空/整个网格），再聚焦到一个（“秋天”星座 / 只剩几颗星）。“全景 → 聚焦”是每一章的内部节奏。
- **静止后爆发**：采样那一下（随机数定格、箭头落下）之后停一拍，才切到暖色的“凉”。
- **层层一章用了 3D 纵深 + 加速线**，是全片唯一的“速度感”高潮，留在了 2/3 处。
- **文字**：标题每幕整体替换（快速淡入 + 轻微上移）；结尾的竖排诗逐字出现，速度明显放慢 —— 慢 = 郑重。

## 5. 声音

- 全程只有配乐，没有旁白（音频没有超过 1 秒的静音，平均 -16 dB）。信息全靠屏幕文案。
- 所以每句屏幕文案都很短（≤ 14 字），一幕只有一句。

## 6. 可以直接复用的“配方”

1. **慢放一件瞬间发生的事**：0.03 秒 / 1 次心跳 / 一次点击 / 一次 DNS 查询……
2. **全片只跟一个具体例子走**，不要每幕换例子。
3. **HUD 外壳 + 章节编号**让几十幕变成一个作品。
4. **冷色的技术过程 → 暖色的人文结局**，结尾用衬线竖排 + 印章升华。
5. **片名放在最后**，作为回答，不要放在开头。
