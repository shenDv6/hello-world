# 视觉设计

视频画面不是网页。网页尺寸在手机竖屏视频里都太小、太淡、太空。

## 1. 先定设计系统（`src/theme.ts`），不许在组件里现编颜色

```ts
export const theme = {
  size: { w: 1080, h: 1920, fps: 30 },
  grid: { x: 72, top: 150, titleY: 360 },      // 左右边距 ≈ 6.5%，标题固定高度
  color: {
    bg: "#070b12",        // 带色相的深色，不用纯黑
    bgGlow: "#0f2a33",    // 径向光
    fg: "#e6f4f3",        // 往强调色偏的白
    dim: "rgba(230,244,243,0.45)",
    faint: "rgba(230,244,243,0.18)",
    accent: "#5ee6e0",    // 全片唯一强调色
    // 转折段第二套
    warmBg: "#140c06", warm: "#f5a23a", warm2: "#e8612c", seal: "#c8322a",
  },
  font: {
    sans: "Noto Sans SC",   // 中文标题/正文
    serif: "Noto Serif SC", // 升华段
    mono: "JetBrains Mono", // 数字/HUD/标签
  },
};
```

## 2. 色彩

- **一个底色 + 一个前景色 + 一个强调色**。中性色都往强调色的色相偏，不要死灰。
- 强调色只给**当前焦点**：同一帧里发光的主元素 ≤ 1 个。
- 如果要换色（情绪转折），**全片只换一次**，而且要有理由。
- 暗色背景不要用全屏线性渐变（H.264 压缩后会出现色带），用纯色 + 局部径向光。
- 要警惕 AI 最爱的默认配色：紫蓝渐变、霓虹、渐变文字。除非主题真的需要，不要用。

## 3. 字号（以 1080×1920 为准）

| 元素 | 网页习惯 | 视频要用 |
| --- | --- | --- |
| 巨型数字/结果字 | — | 240–520px |
| 标题 | 32px | 56–72px（粗体） |
| 正文/说明 | 16px | 32–44px |
| HUD 标签/数据标注 | 12px | 20–26px（等宽） |
| 装饰透明度 | 3–8% | 10–25% |
| 线宽 | 1px | 1.5–3px |

写出小于 20px 的字号，或者低于 10% 的透明度，先说服自己为什么需要。

## 4. 字体

- 中文用真正加载进来的字体（Noto Sans SC / Noto Serif SC），**不要依赖系统默认字体**，渲染机上可能没有中文字体，会变成方块。
- 数字一律用等宽字体 + `font-variant-numeric: tabular-nums`，滚动计数时不会抖。
- 英文小标签：全大写 + `letter-spacing: 0.18–0.25em` + 小字号 + 低透明度 —— 这一个细节就能显得“有设计感”。
- 一种情绪一套字体：技术段用黑体 + 等宽，人文段用宋体/衬线，可以竖排。

## 5. 版式

- **靠边对齐 + 固定网格**。标题左对齐，放在固定高度，每幕只换内容不换位置。
- **三层结构**，每一幕都要有：
  - 背景层：径向光、星尘/颗粒、极淡的网格或巨大的幽灵字
  - 内容层：这一幕的主视觉
  - 前景细节层：HUD、数据标注、刻度、细线、编号 —— “做过设计”的感觉主要来自这一层
- 至少两个视觉焦点，让视线有路径可走（比如“左边大数字 ↔ 右边概率柱”）。
- 9:16 安全区：关键内容放在中间 75% 高度内，底部 20% 留给平台 UI（标题、按钮会盖住）。
- 连接线要有用：每条线都要能说出起点、终点和作用；说不出来就删掉。

## 6. HUD 外壳（讲解类视频强烈推荐）

一套贯穿全片的界面外壳，让所有幕属于同一个“仪器”：

```
━━━━ ━━━━ ━━─── ──── ──── ──── ────        ← 分段进度条（段数 = 章节数）
03 语义 MEANING                  t = 0.0095 s   ← 章节号(强调色等宽) 中文 英文小字 | 计数器
                                   慢放 1000 倍
意思相近的词，住得也近                         ← 标题，固定位置，左对齐
```

- 计数器要讲故事：让它在整片里单调推进，转折时突然加速或跳变。
- 进度条当前段按本章时长填满，给观众一种“知道还剩多少”的安心感。

## 7. 数据可视化

- 全部手写 SVG/Canvas/div，**不用图表库的默认样式**。
- 不要网格线、图例、密集刻度；最多保留一根极简的细轴。
- 数字一定要有“视觉重量”：配一根填充条、一个比例块、一个发光点。
- “其余/长尾”用斜线填充或极低透明度，把视线留给重点。
- 先展示“全部”（整片星空、整张网格），再聚焦到“一个”——这是讲解视频最有力的揭示方式。

## 8. 质感层（放在最上面）

- 颗粒（film grain）：用 SVG `feTurbulence` 生成，每帧平移一点，透明度 4–8%。
- 暗角（vignette）：`radial-gradient(transparent 55%, rgba(0,0,0,.35))`。
- 发光：只给焦点元素加 `text-shadow` / `drop-shadow`，比如 `0 0 24px accent66, 0 0 60px accent33`。
- 粒子：背景星尘缓慢漂浮，数量多、尺寸小、透明度有层次；位置用 `random(seed)` 生成。
